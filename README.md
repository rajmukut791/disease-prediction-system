# 🧬 Disease Prediction AI

Disease Prediction AI is an intelligent healthcare prediction system designed to analyze user-provided symptoms and predict possible diseases using machine learning techniques.

The system aims to provide an initial health assessment based on symptoms and help users understand possible health conditions. It is intended for educational and research purposes and does not replace professional medical diagnosis.

---

## 📌 Project Overview

The system uses machine learning algorithms to analyze a set of symptoms provided by the user and generate a prediction of the most likely disease.

The project demonstrates the application of Artificial Intelligence and Machine Learning in healthcare-related decision support.

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/rajmukut791/Disease-Prediction-AI.git
```

### 2. Navigate to the Project

```bash
cd Disease-Prediction-AI
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```
